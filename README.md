# King Kong Lab · Бухгалтерія

Telegram-бот + Mini App замість спільної таблиці. Команда заходить зі своїх Telegram, адмін роздає доступ, усі ведуть касу в одному місці.

## Що вміє

- **Дашборд** — баланси всіх рахунків у гривні / доларах / USDT, прибуток місяця, борг клієнтів, графік 12 місяців
- **Операції** — дохід, витрата, переказ між рахунками (з конвертацією за курсом)
- **Проєкти і клієнти** — бюджет, скільки оплачено, маржа, дедлайн
- **Команда** — виплати по людях за місяць / рік
- **Ролі** — адмін, фінансист, команда (свої операції + перевірка адміном), перегляд
- **Заплановані та регулярні** платежі, ранковий дайджест адміну
- **P&L** за рік, курси НБУ, експорт у гарний Excel (операції / рахунки / P&L / проєкти / команда)
- **Журнал** хто що змінив

Адмін — ти. Перший вхід з `ADMIN_IDS` одразу дає роль admin. Усі інші пишуть боту → тобі приходить заявка «Дозволити / Відхилити».

## За 5 хвилин

1. У Telegram: `@BotFather` → `/newbot` → скопіюй токен. Потім `/mybots` → Bot Settings → Menu Button → вкажеш URL після кроку 4.
2. Дізнайся свій id: `@userinfobot`.
3. У папці проєкту:

```bash
cd kk-buh
cp .env.example .env
# заповни BOT_TOKEN і ADMIN_IDS
npm install
node --disable-warning=ExperimentalWarning scripts/seed-demo.js   # приклади, можна пропустити
npm start
```

4. Mini App потребує **HTTPS**. Найпростіше з локальної машини:

```bash
brew install cloudflared
cloudflared tunnel --url http://localhost:3000
```

Скопіюй `https://….trycloudflare.com` у `.env` як `WEBAPP_URL` і перезапусти `npm start`. Той самий URL встав у BotFather → Menu Button / Configure Mini App.

5. Напиши боту `/start` — кнопка «Відкрити бухгалтерію».

Імпорт старої таблиці: File → Download → `.xlsx`, потім

```bash
npm run import -- ~/Downloads/KKLab.xlsx
```

Скрипт сам шукає колонки «дата / сума / тип / категорія / рахунок / проєкт / клієнт / коментар».

## Угоди — як у таблиці «KING KONG LAB ПРОЄКТИ»

Кожен рядок таблиці — угода з тими самими колонками: **Розділ** (Розробки / Реклама / Seo / Ads / Дизайн / Інше), Виконавець, Замовник, Тип роботи, Завдання, Дата початку, Дата завершення, Метод оплати, Передоплата, Передоплата прог., Ціна, Маржа, доп. послуга. Зелений рядок = «Закрита».

Бот рахує сам:
- **Виконавцю всього** = Ціна − Маржа (маржа не вказана → Ціна − Передоплата прог.)
- **Замовник винен** = Ціна − Передоплата · **Виконавцю ще** = Виконавцю всього − Передоплата прог. (у закритої — 0)
- **Підсумки** = маржа угод по розділах і місяцях, у гривнях (за датою завершення або початку — у Налаштуваннях)
- Операції на рахунках (Карта → Картка Mono, ФОП → Monobank ФОП, крипта → USDT, Fh → Fh), борги, виплати команді

Як додати: у боті «🤝 Нова угода» (бот питає кожну колонку по черзі) або Mini App → Угоди → «+ Угода». Закрити угоду — кнопка «✅ Закрити» в «📋 Угоди».
Дані з таблиці завантажуються автоматично при старті з `data/kk-deals-2026.json`; оновлену таблицю можна надіслати боту як .xlsx — угоди оновляться без дублів.

## Запис операцій у чаті

Пиши як зручно — бот сам розбере суму, валюту, клієнта, проєкт, людину, рахунок, категорію й дату і покаже картку на підтвердження (✅ зберегти · ↔️ дохід/витрата · 💳 інший рахунок · ❌):

```
отримала 500$ від ABV за сайт на ФОП
виплата Максу 400$ за бота
-300 грн реклама в інсту вчора
+15к грн підтримка TopTrend
```

- 🎙 **Голосові** й 🧾 **фото чеків** розпізнаються, якщо задано `OPENAI_API_KEY`. Підпис до фото («-450 грн хостинг») працює і без ключа.
- ⚡ **Шаблони** — часті операції в один тап (оренда, підписки, виплати).

## Задачі та сторінки — як у Notion

Вкладка **Задачі** в Mini App:

- **Дошка.** Колонки «Не почато → В роботі → На перевірці → Готово». Картки можна перетягувати: мишкою одразу, на телефоні після короткого утримання.
- **Таблиця.** Кожна клітинка редагується по кліку, сортування по заголовку.
- **Календар** за дедлайнами.
- **Сторінки.** Дерево нотаток, ТЗ і бази знань з вкладеними сторінками. Звідси ж відкривається кошик.

Кожна задача — це окрема сторінка. У ній є властивості: статус, відповідальний, дедлайн, пріоритет, проєкт, теги. Під властивостями — блоковий редактор. Можна додати коментарі, іконку й обкладинку.

Як працює редактор:

- **«/»-меню з типами блоків:** заголовки, чекліст, списки, розгортання, цитата, виноска, код, роздільник, вкладена сторінка.
- **Markdown-скорочення:** `# `, `- `, `1. `, `[] `, `> `, `---`, ` ``` `.
- **Клавіші:** Tab / Shift+Tab змінюють відступ, Alt+↑/↓ переміщують блок.
- **Форматування виділеного тексту:** жирний, курсив, код, маркер, посилання.
- **Блоки:** їх можна перетягувати за ⋮⋮.
- **На телефоні:** над клавіатурою з'являється панель інструментів.
- **Шаблони:** чекліст, ТЗ проєкту, баг, нотатки зустрічі.

Задачі привʼязуються до проєктів. У картці проєкту видно список задач і є кнопка «＋ Задача». На дашборді є віджет «Мої задачі».

У боті:

- `/task Банер для ABV @olena завтра !! #дизайн` або кнопка «📝 Задача». @нік — відповідальний, `сьогодні` / `завтра` / `пт` / `30.10` — дедлайн, `!` / `!!` — пріоритет, `#тег` — тег.
- Відповідальним можна призначити будь-кого: людей із команди або контакти. Новий контакт додається одразу з вибору відповідального (`@нік`, телефон або імʼя), у боті — через `/task … @нік`, кнопку «👤 Призначити» або надісланий контакт (📎 → Контакт). Контакт не має доступу до бухгалтерії. Якщо людина ще не в боті, їй можна переслати підписане посилання `start=task_<id>_<код>`: коли вона його відкриє, її Telegram привʼяжеться до контакту, вона побачить задачу й почне отримувати сповіщення.
- `/tasks` або «✅ Мої задачі» показують відкриті задачі з кнопками ✅ / ▶️ / 📅 На завтра / 🙋 Беру.
- Сповіщення приходять, коли тобі призначили задачу, закрили твою задачу або хтось залишив коментар.
- О 9:00 кожен отримує свої задачі на сьогодні та прострочені.

Посилання на сторінку: `t.me/<бот>?startapp=page_<id>`.

## Google-таблиця

1. На сервері задай `SHEET_SYNC_TOKEN` (будь-який довгий пароль).
2. У таблиці: Розширення → Apps Script → встав `docs/google-sheet-sync.gs` → збережи.
3. Онови таблицю → меню «🦍 KK Бот» → «Налаштувати» → адреса бота і той самий токен.

Аркуші «Операції (бот)» і «Проєкти (бот)» оновлюються кожні 10 хв, зміни рядків одразу йдуть у бот. Помилки (наприклад, неіснуючий рахунок) показуються приміткою на рядку.

## Monobank

1. Візьми особистий токен на https://api.monobank.ua/ і задай `MONO_TOKEN`.
2. Mini App → Ще → Monobank → привʼяжи рахунки → «Увімкнути миттєво».

## Деплой

Працює на будь-якому Node 22+ (Railway, Fly, Render, VPS). Потрібні `BOT_TOKEN`, `ADMIN_IDS`, `WEBAPP_URL` = публічний https цього ж сервісу, `USE_WEBHOOK=1`. База — один файл `data/kkbuh.sqlite`, його варто бекапити.

Локальний превʼю без бота: `DEV_MODE=1 npm run dev` і відкрий `http://localhost:3000/?dev=ТВІЙ_TG_ID`.
